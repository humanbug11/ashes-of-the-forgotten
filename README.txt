蒼の残火 Browser Prototype

遊び方:
1. index.html をChrome / Edge / Safariなどで開きます。
2. 衣装と武器を選び「出撃する」。
3. WASD / 矢印キーで移動。QまたはSpaceで旋風斬り。
   スマホでは左下の方向ボタンと右下の剣ボタンを使用。
4. 敵を倒すと緑のEXPオーブが落ちます。拾ってレベルアップし、3択強化を選びます。
5. 「炎属性」と「旋風斬り強化」が揃うと炎竜巻へ自動合成されます。
6. 残り20秒でボスが登場。時間終了時にボスを倒していればクリアです。

※コンセプト画像から切り出した簡易スプライトを使用するプロトタイプです。
※最終UE5版のゲームバランス・アニメーション・当たり判定とは異なります。
